## Chelabs

**Hacemos que tu idea funcione.**

Compañía de producto digital en Montevideo. Nos hacemos cargo del ciclo
completo: entendemos el negocio, diseñamos la solución, la construimos y la
operamos en producción. Equipos propios, sin capas de gestión.

### Qué hacemos

| | |
|---|---|
| **Entender** | Negocio, usuarios y métricas de éxito, antes de dibujar nada. |
| **Diseñar** | UX, UI y dirección de arte. Prototipos que se prueban, no láminas para aprobar. |
| **Construir** | Front-end, back-end, integraciones e IA donde acelera de verdad. |
| **Sostener** | Deploy, métricas, monitoreo y soporte. Lo que sale se sigue mejorando. |

### Con qué

Next.js · TypeScript · React · Tailwind · Supabase · PostgreSQL · Vercel
